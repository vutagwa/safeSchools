**Safe Schools** is a responsive web and mobile application designed to improve safety in schools by enabling real-time incident reporting, emergency communication, and access to safety resources.

---

## 🌟 Features

- 🛎️ **Quick Incident Reporting** (anonymous or named)
- 📚 **Awareness Hub** for safety articles and updates
- 📞 **Emergency Contacts** & 1-tap SOS trigger
- 📍 **Location-based Alerts** for real-time threats
- 🧑‍🏫 **Admin Panel** for school safety management
- 🔐 **Privacy-first** with encrypted data & role control

---

## 🖼️ UI/UX Design Suggestions

Design your app with simplicity, clarity, and student-friendliness:

### 🔵 Student View
- Clean dashboard with icons: "Report", "Emergency", "Learn"
- Soft blue and white color theme for calmness
- Emoticon-based feedback after reporting

### 🟣 Admin View
- Dashboard with report analytics (pie charts, heatmaps)
- Tabs for reports, user management, alert system
- Dark mode for extended use

### 🟢 Guardian View *(Optional)*
- Overview of child reports, emergency alerts, school bulletins

You can use **Figma**, **Adobe XD**, or **Penpot** for design mockups.

## 🛠️ Setup Instructions

# Clone the repository
git clone https://github.com/yourusername/safe-schools.git
cd safe-schools

# Install dependencies
npm install

# Add Firebase configuration to /src/firebaseConfig.js

# Start development server
npm start
